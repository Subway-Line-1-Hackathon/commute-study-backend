# R9 과목 삭제 (#86)

`DELETE /api/subjects/{id}`는 Bearer JWT 인증 후 본인 과목을 소프트 삭제한다. 기존 학습 세션, 문제, 답안, 오답노트, 해설, 리포트와 FK 참조를 유지한다.

| 조건 | 응답 |
| --- | --- |
| 본인 과목 삭제 및 반복 삭제 | 204, 응답 본문 없음 |
| 인증 없음 | 401 |
| 없는 과목 또는 다른 사용자 과목 | 404 NOT_FOUND |
| UPLOADED/PROCESSING 자료가 하나라도 존재 | 409 STATE_CONFLICT, 전체 변경 롤백 |

## 삭제와 조회

과목과 관련 자료의 삭제 표시 및 R8 Storage 정리 예약을 한 트랜잭션으로 커밋한다. 204는 이 DB 커밋이 완료되었다는 뜻이며 Storage 원본 삭제 완료를 뜻하지 않는다. 자연 만료 EXPIRED와 삭제 표시는 구분한다. 이미 R8으로 삭제한 자료는 중복 예약하지 않는다.

과목·자료 일반 목록과 신규 학습 선택에서 제외한다. 과목별 과거 기록 URL, 기존 세션, 오답노트, 해설과 통계는 소유권 검증 후 계속 조회할 수 있다. 삭제된 과목에 PATCH 또는 신규 업로드를 하면 404다. 마지막 과목을 삭제하면 hasSubject는 false지만 닉네임·통학 설정을 갖춘 계정은 ACTIVE를 유지한다.

## 경합 처리

- 과목 삭제, PATCH, 자료 삽입 및 worker는 과목 행을 먼저 잠근다. 과목 삭제는 자료 ID 오름차순으로 자료도 잠근다. 처리 중 자료가 발견되거나 정리 예약이 실패하면 앞선 자료 변경까지 롤백한다.
- Storage 업로드는 DB 트랜잭션 밖에서 수행한다. 자료 삽입 트랜잭션에서 활성 과목과 소유권을 재확인한다. 업로드 중 과목이 삭제되었다면 삽입을 거부하고 업로드한 모든 객체를 보상 삭제한다. 보상 삭제 실패는 R8 큐에 영속화하며, 자료 행 생성 이전의 객체는 material_id=0을 사용한다. 실제 자료 ID는 양수 identity다.
- 문제 생성과 신규 세션은 R8의 자료 잠금·삭제 재확인을 재사용한다. 이미 전송된 AI 호출은 취소하지 않지만 삭제 후 결과 저장과 추가 생성 라운드는 차단한다. 세션 저장이 먼저 끝난 경우 해당 세션을 과거 기록으로 보존한다.
- Storage 큐는 프로세스 재시작 후에도 남는다. 객체별 성공을 기록하고 실패를 재시도하며 원본 삭제는 멱등성을 전제로 한다. 기존 R8 스케줄러 설정을 그대로 사용한다.

Storage HTTP와 DB는 분산 트랜잭션이 아니다. 업로드 직후 프로세스가 강제 종료되거나 Storage 보상 삭제와 DB 정리 예약이 동시에 실패하는 경우까지 원자성을 보장하지 않는다. 이 기존 업로드 구간의 장애에는 객체 대사·정리 절차가 필요하다. 실패한 DB 예약은 오류 로그로 남기며 객체 참조나 인증키는 기록하지 않는다. 추출 원문 보관 기간과 과목별 기록의 UI 노출 방식은 별도 운영 정책으로 정한다.

## 재현 가능한 검증

```powershell

node --test scripts/swagger-auth.test.cjs
.\scripts\test-r9-postgres.ps1 -JavaHome 'C:\Program Files\Java\jdk-21.0.12.1'
```

PostgreSQL 스크립트는 postgres:16 컨테이너를 임의 이름으로 생성하고 127.0.0.1의 임의 포트에만 공개한다. Flyway V1~V9 적용 후 기존 데이터가 있는 상태에서 V10을 적용·검증하고 API·동시성 테스트를 수행한다. Mock Storage와 Mock AI만 사용하며 컨테이너와 볼륨은 finally에서 제거한다. 기존 Docker 컨테이너에는 접근하지 않는다. `postgresTest`는 별도 실행 작업이며 기존 `test` 작업의 검증을 제거하지 않는다.

2026-11-13 통합 검증 결과: Java 전체 703개, PostgreSQL 16.15 통합 20개, JavaScript 10개 성공. 각 실행의 실패 및 건너뜀은 0개다. R7 `90544f5`, R9 PATCH `7ee343f`, R8 `80ff167`을 결합한 코드에서 검증했다.
